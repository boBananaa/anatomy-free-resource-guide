# Anatomy Free Resource Guide

A lightweight, single-file study app for OpenStax *Anatomy & Physiology 2e*. No install and no accounts: open `index.html` in a browser.

## What it does
- Walks each chapter in order: **watch** a video, **read** the OpenStax sections, then take a **10-question quiz** for each of the 6 units.
- Tracks videos watched, lessons read and quiz scores. Progress saves in your browser only (use Export and Import to move it).
- Lists free 3D models, histology sites, flashcard tools and extra reading, with their cost labeled.

## Notes
- Textbook links point to the free online book at [openstax.org](https://openstax.org/details/books/anatomy-and-physiology-2e). The book is not copied here.
- Video links are YouTube searches, not direct video links.
- The quiz questions were written for this project. If you spot a mistake, open an issue.
